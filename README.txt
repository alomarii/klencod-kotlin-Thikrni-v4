تطبيق ذكرني - تذكير بالصلاة على النبي صلى الله عليه وسلم
برمجة وتطوير: محمد العمري - 730215825

طريقة التشغيل:
1) افتح المجلد Thikrni في Android Studio (إصدار Hedgehog أو أحدث، JDK 17).
2) انتظر مزامنة Gradle ثم اضغط Run أو Build > Build APK(s).
3) عند أول تشغيل اسمح بالإشعارات، ثم اضغط "السماح بالعمل في الخلفية" (من الإعدادات) ليعمل التذكير عند الشحن وفتح القفل بشكل ثابت.
الحد الأدنى: Android 7.0 (API 24)

========================================================
الإصدار ٢٫٠ - واجهة جديدة وميزات جديدة
========================================================
الواجهة: شاشة بداية متحركة + شريط تنقل سفلي بمؤشر منزلق + انتقالات بين أربع صفحات:
  الرئيسية | إحصائياتي | الصوتيات | الإعدادات

الميزات:
- أوقات الصمت: تحدد ساعات (مثل النوم أو العمل) لا يُشغَّل فيها أي صوت أو تنبيه.
- عدة تسجيلات صوتية: أضف حتى ١٢ تسجيلًا، وتُختار عشوائيًا (بدون تكرار متتالٍ) أو بالترتيب.
- عدّاد تلقائي: كل تذكير يُسمَع يُضاف للعدّاد، مع إحصائيات اليوم والأسبوع والشهر والإجمالي ورسم بياني لآخر ٧ أيام.
- هدف يومي: شريط تقدم متحرك، واحتفالية وإشعار خاص عند إتمامه.
- تكثيف يوم الجمعة: من مساء الخميس (٦ م) إلى مساء الجمعة (٦ م) يقصر الفاصل بين التذكيرات.
- ويدجت الشاشة الرئيسية: التاريخ الهجري والميلادي وعدّاد اليوم وزر "صلِّ على النبي".
- أذكار قصيرة: إشعار هادئ بدون صوت في منتصف المدة بين تذكيرين (اختياري).
- مناسبات هجرية: رأس السنة، عاشوراء، المولد النبوي، رمضان، العشر الأواخر، العيدان، العشر من ذي الحجة، يوم عرفة (تنبيه صباحي ٨ ص).
- ثيمات: زمردي، أزرق ليلي، ذهبي.
- مشاركة التطبيق: رابط مع دعاء (غيّر AppConfig.SHARE_URL إلى رابط تطبيقك).
- عدّاد الأجهزة (يحتاج إعدادًا لمرة واحدة، انظر أدناه).

========================================================
تحديث: إصلاح الصوت + تأثير Venom
========================================================
- إصلاح: كانت إضافة التسجيلات تفشل بسبب اسم الملف المؤقت (Prefix قصير). صار الملف يُنسخ بامتداده الأصلي،
  ويُفحص أنه قابل للتشغيل قبل حفظه، وتظهر مدته بجانب اسمه. وإن تعذّر تشغيل تسجيل تُجرَّب بقية التسجيلات.
- زر "لا تجد ملفك؟ استعرض كل الملفات" في صفحة الصوتيات لعرض كل أنواع الملفات.
- تأثير Venom (الفقاعات اللزجة): زر الصلاة الرئيسي، وأزرار (إضافة تسجيل، جرّب التذكير، مشاركة)، ومؤشر شريط التنقل.
  الدمج السائل الكامل يعمل على أندرويد ١٢ فأحدث (RenderEffect)، وفي الأقدم تتحرك الأشكال بدون الدمج.

========================================================
تحديث: أنيميشن أقوى + زر الويدجت + ثيمات جديدة
========================================================
- ثمانية ثيمات: زمردي، أزرق ليلي، ذهبي، بنفسجي، ياقوتي، فيروزي، فحمي (أسود)، غروب. والويدجت يتبع الثيم المختار.
- زر "إضافة الويدجت" في الرئيسية (بطاقة بمعاينة حية، تختفي بعد إضافته) وفي الإعدادات. يعمل بنافذة تأكيد من النظام على أندرويد ٨+، ويُعرض شرح يدوي إن لم يدعمه الهاتف.
- أنيميشن: شرارات نجمية و"+١" تصعد عند كل ضغطة، عدّاد يتدحرج رقمه، شريط الهدف بشرارة عند رأسه ووهج عند الإتمام،
  أعمدة الرسم البياني تنبثق بالتتابع، بطاقات تظهر بنبضة نابضية، انتقال بين الصفحات بتكبير وانزلاق،
  شهب تعبر الخلفية وشفق متحرك، حلقات ضوئية في شاشة البداية، واهتزاز خفيف عند النقر على التنقل والمفاتيح.

========================================================
تفعيل عدّاد الأجهزة (مرة واحدة، مجاني)
========================================================
التطبيق لا يملك خادمًا خاصًا، لذلك يستخدم قاعدة Firebase Realtime Database المجانية عبر REST (بدون أي مكتبات):
1) ادخل console.firebase.google.com وأنشئ مشروعًا، ثم أنشئ Realtime Database (اختر وضع القفل Locked mode).
2) انسخ رابط القاعدة، مثال: https://اسم-المشروع-default-rtdb.firebaseio.com
3) من تبويب Rules الصق القواعد التالية ثم Publish:

{
  "rules": {
    "devices": {
      ".read": true,
      ".indexOn": ["seen"],
      "$id": {
        ".write": true,
        ".validate": "newData.hasChildren(['seen']) && $id.length <= 64",
        "seen": { ".validate": "newData.isNumber()" },
        "$other": { ".validate": false }
      }
    }
  }
}

4) افتح الملف app/src/main/java/com/alikhwa/thikrni/AppConfig.java وضع الرابط في DEVICES_DB_URL ثم أعد بناء التطبيق.

ملاحظات:
- كل تثبيت يرسل معرّفًا عشوائيًا مجهولًا ووقت آخر ظهور فقط، دون أي بيانات شخصية.
- يظهر العدّاد في الرئيسية وفي صفحة "إحصائياتي" (إجمالي الأجهزة + النشطة خلال أسبوع).
- القواعد أعلاه تسمح لأي شخص يعرف رابط القاعدة بالكتابة فيها (مناسب لعدّاد بسيط). للحماية من العبث يمكن لاحقًا استخدام Firebase App Check.
- ما دام الرابط فارغًا يختفي العدّاد من الرئيسية ويظهر في الإحصائيات "غير مفعّل بعد".

تعليمات الصوت:
- من صفحة "الصوتيات" اضغط "إضافة تسجيل صوتي" واختر تسجيلًا أو أكثر بصوت قارئ فصيح (mp3/m4a/ogg/wav).
- أو ضع ملفًا باسم salawat.mp3 داخل app/src/main/res/raw/ قبل البناء ليكون الصوت الافتراضي.
- تسجيلك المخصص من الإصدار السابق يُنقل تلقائيًا إلى المكتبة.

========================================================
تحديث: شخصية مستقلة لكل ثيم (أشكال + حركة)
========================================================
كل ثيم الآن له شكل أزرار وبطاقات، ومؤثر أزرار، وحركة ضغط، وظهور، وانتقال بين الصفحات، وخلفية متحركة، وزر رئيسي مختلف:
- زمردي (سائل): كبسولة Venom، نجوم وشهب، انتقال انزلاقي.
- أزرق ليلي (زجاجي): زوايا ناعمة، زجاج بتموّج، شفق قطبي، أقمار تدور حول الزر، انتقال بعمق.
- ذهبي (زخرفي): زوايا مقصوصة، لمعان يعبر الأزرار، نجمة ثمانية دوّارة، غبار وأشعة ذهبية، انتقال تكبير.
- بنفسجي (عضوي): زوايا غير متماثلة، سائل بضغط مطّاطي، يراعات، انتقال قلب ثلاثي الأبعاد.
- ياقوتي (جوهري): شكل بتلة، معيّن نابض، بتلات متساقطة، انتقال مائل.
- فيروزي (مائي): شكل ورقة، موجة وتموّج، ماء يتماوج داخل الزر، فقاعات، انتقال مرن.
- فحمي (نيون): زوايا حادة، إطار نيون متوهج بشرارة تدور، مسح ضوئي هادئ، حركة سريعة وحادة.
- غروب (شروق): شكل قوس، شمس بأشعة، جمرات صاعدة، انتقال صعود.
وأيضًا: كشف دائري/معيّني/ستارة عند تغيير الثيم من مكان الضغط، تأثير عمق أثناء التمرير، وخلفية تتحرك مع ميل الهاتف.
الملفات الجديدة: Style, Shapes, ShapeBg, Motion, ThemeReveal. أي ثيم جديد تضيفه عدّل له سطرًا في Style.ALL.

========================================================
تحديث ٣٫٠: ميزات جديدة
========================================================
- السلسلة المتتالية: عدد الأيام التي أُتمّ فيها الهدف، بلهب متحرك (الرئيسية والإحصائيات)، وتنبيه ٨ مساءً قبل انقطاعها.
- ١٠ إنجازات/أوسمة (إجمالي الصلوات، السلاسل، يوم مبارك) بنافذة احتفال وإشعار إن كان التطبيق مغلقًا.
- بطاقة إنجاز للمشاركة كصورة بشكل وألوان الثيم (صفحة الإحصائيات).
- اختيار الصيغة المفضلة للصلاة على النبي أو التبديل التلقائي (الإعدادات).
- التذكير بعد الصلاة: تُدخل أوقات الصلوات الخمس يدويًا وتحدد المدة بعد كل صلاة.
- تخفيف الحركة (يعمل تلقائيًا أيضًا إن أوقفتَ الحركة من إعدادات الهاتف)، واهتزاز خاص بكل ثيم.
- وضع الجلسة: شاشة كاملة للذكر المتواصل مع إبقاء الشاشة مضاءة.
- مظهر تلقائي: ذهبي في ليلة الجمعة ويومها، وأزرق ليلي من ٩ م إلى ٥ ف.
- مرئيات الجمعة: هالة ذهبية وأشعة فوق أي ثيم في ليلة الجمعة ويومها.
- نسخ احتياطي واستعادة (ملف JSON) للعدّاد والإحصائيات والإنجازات والإعدادات.
- ويدجت صغير ١×١ بزر واحد وعدّاد اليوم.
ملاحظة: لم تُضف تعددية اللغات لأن نصوص الواجهة العربية مكتوبة داخل الكود وتحتاج استخراجًا كاملًا إلى ملفات strings.

========================================================
تحديث ٤٫٠: اللغات + مواقيت الصلاة + قائمة إعدادات احترافية
========================================================
- ٦ لغات: العربية، English، Français، Türkçe، اردو، Indonesia (+ «لغة الهاتف»). الاتجاه RTL/LTR يتبدل تلقائيًا.
  النصوص العربية هي مفاتيح جدول الترجمة Tr.java (صف لكل نص: ar, en, fr, tr, ur, id). لإضافة نص جديد: اكتبه بالعربية في الكود
  (ui.text / L.t / L.f للقوالب {0}) وأضف صفًا له في Tr.java؛ وإلا يبقى عربيًا. الأذكار وصيغ الصلاة على النبي تبقى عربية عمدًا.
- مواقيت الصلاة: حساب فلكي دون إنترنت من موقعك (إذن ACCESS_COARSE_LOCATION يُطلب مع شرح)، ٥ طرق حساب، العصر جمهور/حنفي،
  بطاقة في الرئيسية بالصلاة القادمة وعدّ تنازلي، وتذكير بعد كل صلاة. ويمكن إدخال الأوقات يدويًا بدل الموقع.
- الإعدادات: ٦ أقسام قابلة للطي (تذكير، مواقيت، أهداف، مظهر ولغة، أدوات وبيانات، عن التطبيق) بترويسات أيقونية وحركة فتح/إغلاق.
